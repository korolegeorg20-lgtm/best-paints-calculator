# Best Paints Калькулятор

Интерактивный прототип конструктора тендерных смет для Best Paints.

Возможности:

- смета для рабочих с редактируемыми объёмами и расценками;
- расчёт материалов;
- расчёт себестоимости, прибыли и маржинальности;
- финансовые сценарии;
- условия тендера и риски;
- демонстрация загрузки и AI-анализа документов;
- экспорт сметы для Excel.

Публичная версия автоматически обновляется через GitHub Pages после каждого изменения ветки `main`.
